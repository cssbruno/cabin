# Cabin 0.1.9

- Point Carlink library imports directly at the supplied Joying UIS7862 20230831 `AllAppUpdate (1)` firmware folder.
- Verify the packaged receiver, CarPlay plugin, audio and echo-cancellation libraries against their pinned checksums. These match the binaries used in 0.1.8; this release changes source provenance, not the native engine behavior.
- Retain the app-owned Carlink startup path: load `libcps_7862.so`, create its receiver, register callbacks, and send the native startup and video requests.

Includes the signed APK, checksums, update metadata and additive OEM integration ZIP. Release automation runs unit tests, native transport tests, and engine/OEM packaging checks before publishing.

The imported engine requires ARM64 Android 10 and compatible head-unit firmware. Physical startup, phone pairing, audio and video remain unverified on the head unit.
