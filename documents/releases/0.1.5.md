# Cabin 0.1.5

- Detect FYT field mappings from the installed firmware bytecode and select SYU callbacks by the complete CAN profile ID.
- Add searchable live CAN and MAIN field viewers and decoded SYU readings using verified stock display calculations, option labels and units.
- Correct Joying maintenance-distance, temperature and seat readings. Require current unit/sign feedback and avoid interpreting clock values as maintenance or oil-life percentages.
- Clear readings on profile changes, disconnect and expiry. Recognize valid decoded SYU data in the connection status.
- Add access to the installed SYU settings for vehicle-specific controls that remain outside Cabin.
- Move CCPA adapter controls out of Launcher settings and into CarPlay → CCPA → Controls.

Coverage is not full parity with every SYU field or command. Unrecognized calculations remain unavailable; raw fields remain inspectable. The original SYU settings action opens the vendor app, rather than implementing its controls inside Cabin.

Validated locally with 68 focused tests and a minified release build. Hardware operation still requires verification on the head unit.
