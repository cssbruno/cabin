# Cabin 0.1.8

- Keep the selected CCPA adapter when USB temporarily disconnects, instead of switching to Carlink.
- Stop pending Carlink retries when changing modes and wait for the previous engine to close before switching.
- Prevent stale service starts from restarting Carlink while CCPA is selected. Disable native connection commands in CCPA mode.
- Separate CCPA adapter settings from Carlink and launcher settings, and fix the projection settings shortcut to open the CCPA controls.
- Add persistent Carlink frame rate, Wi-Fi band, automatic connection and logo settings, plus verified microphone setting writes.
- Route supported FYT volume and mute controls through the factory sound service.
- Make quick controls scroll on short displays and apply brightness changes to the dialog window too.

Validated with local unit tests, native transport tests and engine/OEM packaging checks. Physical Carlink video and CCPA handover still require testing on the head unit; this release does not claim hardware verification.

Includes the signed APK, checksums, update metadata and additive OEM integration ZIP.
