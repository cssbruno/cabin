## Cabin 0.1.3

Fixes the FYT connection failure identified in Joying firmware and adds an in-app log viewer.

- FYT accepts the empty replies returned by Joying's command and callback-registration methods. Previously these successful calls were treated as failures, causing disconnects and repeated retries. Legacy Teyes exception replies remain supported.
- CAN retries can switch to the direct service when toolkit subscription setup fails.
- Live CAN diagnostics use the same corrected reply handling.
- Open **Settings → Registros → Ver** (or tap a log file) to read logs directly in a dark viewer. Previous/next pages, refresh and text selection are available; export remains available.
- The updater supports firmware that supplies only legacy signing metadata and verified forward signing-key rotation. Missing or unrelated signing certificates are rejected.

### Install and test

Install **cabin.apk** over the previous release, or use **Settings → Launcher → Updates**. The package and release signing key are unchanged.

On Joying, check whether FYT stays connected and receives vehicle data. The protocol fix is verified against the reference Joying smali and automated tests; physical head-unit operation and individual vehicle mappings still require testing. This release does not introduce a new CarPlay socket fix.

The OEM ZIP is an additive integration bundle, not a self-installing USB update.
