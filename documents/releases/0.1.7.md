# Cabin 0.1.7

Carlink now imports its native receiver libraries into Cabin and runs the engine
in a private app process. The projection path no longer starts or binds to the
stock Car Link app or firmware daemon. The connection is labeled **Carlink**.

- Separate Carlink video socket and app-owned pairing-data storage.
- Remove stock-app settings, takeover controls and the force-stop permission.
- Preserve in-app video, touch, phone selection, wireless setup and recovery.
- Improve climate temperature controls and expose supported vehicle options.
- Add verified, user-triggered self-updates where firmware grants installation privileges; retain Android confirmation when required.
- Improve local diagnostics and crash-report context.

**Carlink device support is not yet verified.** The imported engine targets
ARM64 Android 10 and requires compatible system libraries plus authentication,
USB, audio and wireless hardware access. No physical head-unit CarPlay session
has been tested. Other Cabin features retain Android 8.1+ support.

The signed APK, SHA-256 checksums, update metadata and additive OEM integration
ZIP are attached. The OEM ZIP is not a self-installing USB firmware update.
