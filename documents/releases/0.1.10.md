# Cabin 0.1.10

- Fix CCPA screen reattachment to an existing session: send the current connection state, status and phone type to the replacement UI callback. This prevents a stale connection overlay from covering streaming video.
- Keep the underlying Carlink error visible during automatic retries and after the retry limit is reached, instead of replacing it with a generic reconnect message.
- Add regression coverage for streaming-state delivery and recovery error preservation.

Includes the signed APK, checksums, update metadata and additive OEM integration ZIP. Release automation runs unit tests, native transport tests and engine/OEM packaging checks before publishing.

The reported head-unit Carlink reconnect failure is not yet diagnosed; this release exposes its error rather than claiming to fix its underlying cause. Physical CCPA video and Carlink operation still require head-unit validation.
