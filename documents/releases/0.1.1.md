## Cabin 0.1.1

Expanded optional Sentry reporting to help diagnose problems during head-unit testing.

- Java/Kotlin and native crash reporting, plus app-freeze detection.
- Diagnostic logs with severity and code location, connection breadcrumbs, and handled-error reports from the central logger, updater and Joying paths.
- Privacy filtering removes raw log messages, exception text, phone/media data and attachments. Reporting remains off by default.
- Rate limits keep noisy hardware from flooding diagnostic reports.
- Automatic R8 mapping and native symbol uploads make release crashes easier to diagnose.
- Queued crashes retain their original version and mapping after app updates.

### Install and test

Install **cabin.apk** over Cabin 0.1, or use **Settings → Launcher → Updates**. The application identity and signing key are unchanged.

Enable **Settings → Logs → Share crash reports**, then tap **Send test report**. A queued report still needs an internet connection to reach Sentry.

Physical head-unit crash, ANR, native-crash and driving-hardware validation remains pending. The OEM ZIP is an additive integration bundle, not a self-installing USB update.
