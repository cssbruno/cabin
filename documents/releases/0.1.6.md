# Cabin 0.1.6

- Replace runtime vendor-bytecode readers with Cabin-owned native SYU implementations and versioned protocol facts.
- Expand Honda support with additional capabilities on 49 profiles: Civic/CR-V factory media, Accord XP/WC/XBS settings and trips, Acura amplifier controls, Spirior instruments, and earlier Honda trip data.
- Correct protocol-specific field IDs, units, signed values and read commands. Require current feedback before changing settings.
- Add native Honda, Golf, Ford and GM controls and readings, including supported trip, tire, lighting, door, camera and amplifier functions.
- Improve Joying connection recovery and keep native CarPlay configuration separate from CCPA adapter settings.
- Provide searchable vehicle readings and local log inspection.

Support is still being expanded. This release does not implement every Honda or SYU feature, and local verification does not establish operation on every head unit.

Validated locally: 841 tests passed, one optional reference-export test skipped, and a minified release APK compiled successfully. No vendor bytecode interpreter or reference reader is included in the runtime APK.
