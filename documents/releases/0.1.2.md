## Cabin 0.1.2

Improves Joying CarPlay handoff and FYT service compatibility following head-unit reports.

- CarPlay keeps actionable socket errors visible and stops automatically repeating known socket conflicts, permission denials or blocked handoffs. Manual Retry remains available.
- New **Stock Car Link settings** shortcut opens Android’s app settings so you can force-stop the stock client when it keeps the video socket occupied.
- FYT radio, sound, steering, audio-source and factory Bluetooth connections can use an exported direct module when the toolkit endpoint is unavailable or inaccessible.
- Sentry retains safe socket-failure codes and breadcrumb severity, reports FYT bind/module failures, and omits misleading reporting-thread stacks from message warnings.
- Duplicate Joying recovery-exhausted warnings are suppressed. Real exception and ANR stack collection remains enabled.

### Install and test

Install **cabin.apk** over the previous release, or use **Settings → Launcher → Updates**. The package and signing key are unchanged.

If CarPlay reports a busy video socket, tap **Stock Car Link settings → Force stop**, return to Cabin and tap **Retry**. Closing the stock screen alone may leave its service running. Firmware may restrict Force stop; Cabin does not gain additional system permissions from this update.

These changes passed 714 app tests and 154 diagnostics tests locally. Physical Joying verification is still required: they address app-side compatibility and reporting, but do not establish that the firmware grants every required service permission. The OEM ZIP remains an additive integration bundle, not a self-installing USB update.
