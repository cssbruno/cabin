## Cabin 0.1

The first release under Cabin's plain numeric version scheme. Future releases will use numbers such as 0.2, with no alpha suffix or prerelease label.

- Dark mode by default for new profiles, preserving saved appearance choices.
- Embedded Joying CarPlay and bounded connection recovery.
- Optional Sentry reporting in **Settings → Logs → Share crash reports**.
- FYT radio, sound, Honda panel and steering controls for supported firmware/profiles.
- Updates now recognize two-part version numbers.

### Install
Download **cabin.apk** and install it over the previous release. The signing identity is unchanged and the Android version code is higher, preserving a normal upgrade path. Older builds do not recognize the new two-part tag, so install this release manually once.

Physical CarPlay, CAN, audio and sleep/wake validation remains pending. Camera/radar integration and full SYU replacement remain incomplete. The OEM ZIP is an additive integration bundle, not a self-installing USB update.
