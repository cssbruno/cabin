## Cabin 0.1.0-alpha.10

### Changes
- New driver profiles start in dark mode; saved appearance choices are preserved.
- Embedded Joying CarPlay with phone selection, wireless setup, native audio focus and service handoff.
- CarPlay session recovery retries after 2, 4 and 8 seconds, with cancellation on Disconnect.
- Optional Sentry crash and recovery reporting, configured for Cabin. Enable it in **Settings → Logs → Share crash reports**. Reporting starts off; screenshots, audio, GPS, phone details and raw logs are excluded.
- Native FYT radio/sound controls, Honda panel settings and steering-button mapping improvements, gated by firmware/profile support.
- Clearer update errors and completed interface translations.
- Release publishing now requires app, diagnostics and native transport tests.

### Install and test
Download **cabin.apk**. The release uses Cabin's existing signing identity.
After installing, enable crash reporting and tap **Send test report** to check delivery.

Physical Joying CarPlay, CAN controls, audio routing and sleep/wake behavior still need head-unit testing. Camera/radar integration and full SYU replacement remain incomplete. The OEM ZIP is an additive integration bundle, not a self-installing FYT USB update.
