# Cabin 0.1.0-alpha.5

Car Settings now groups existing vehicle controls in one place: lights, mirrors and wipers, parking and camera, comfort, audio and steering, and personal vehicle settings. Supported hybrid vehicles also have charging preferences.

- Factory controls require a verified vehicle profile and fresh feedback, and retain the parked-action guard.
- Includes the current dashboard, climate, vehicle history, appearance and compatibility improvements.
- Labels support English, Portuguese, Spanish, French, German and Italian.

## Downloads

- **cabin.apk**: signed Android app (Android 8.1 or later).
- **cabin-oem-integration.zip**: additive integration files for firmware integrators; this is not a self-installing FYT USB update.
- SHA-256 files and update metadata are included.

This is an alpha release. Actual vehicle functions depend on the head unit and CAN profile; physical head-unit validation remains necessary. Camera mode selection does not provide camera video. A debug installation uses a different signing key and may need to be removed before installing the signed release.
