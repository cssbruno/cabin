## Language and actual cluster entry points

- Android/head-unit language and vehicle/cluster language are separate paths. Brazilian Portuguese head-unit locale is `pt_BR`. Vehicle language is already in the XML catalog (`03/0E`), so it is not an additional setting. See the existing [stock language review](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/stock-language-review.md).
- Tachometer visibility is already cataloged (`03/5C`). The Settings handler is `requestTachometerSettingChange` and calls `setTachometer`; the prior vehicle-service audit traces the vehicle write. Do not double-count this system-menu shortcut. [SystemSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/system-source/SystemSettingActivity.smali:2241)
- Configure Meter launches `com.mitsubishielectric.ada.app.externaldisplay.CustomizeMeter`; this is a distinct target from `ClockWallpaperTypeActivity`. The separate meter audit owns its controls. [SystemSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/system-source/SystemSettingActivity.smali:4316)

### Applicability and unresolved details

- DaSettings reads equipment keys `RearWideCamera`, `FrontCamera`, `CornerCamera`, `LaneWatch`, then opens the Camera settings application. This is runtime equipment gating, not evidence that every camera exists on the user's Civic. [GroundSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/system-source/GroundSettingActivity.smali:857); [GroundSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/system-source/GroundSettingActivity.smali:2140)
- The extra `CAMERA_PARKING_SENSOR` rear-camera row is explicitly conditional on `CameraSystemInfo.isDeriveVehicle()`. It is excluded from the five confirmed generic rear/LaneWatch preference rows above; Civic applicability is unresolved. [RearWideCameraSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/camera-source/com/mitsubishielectric/ada/app/camera/activity/RearWideCameraSettingActivity.smali:2304)
- The on/off helper uses integer enum values `[1,0]`, with the two label IDs supplied by each listener. The exact label/resource decoding and persistence inside CameraAPService are not completed here. [CameraAppSettingBaseActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/camera-source/com/mitsubishielectric/ada/app/camera/base/CameraAppSettingBaseActivity.smali:1999)
- `setLaneWatchSettingState(1/0)` marks settings-session entry/exit; it must not be exposed as “enable/disable LaneWatch.” [LaneWatchSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/camera-source/com/mitsubishielectric/ada/app/camera/activity/LaneWatchSettingActivity.smali:1648); [LaneWatchSettingActivity.smali](/home/bruno/Documentos/ChatGPT/R/honda-cluster-analysis/oem-civic/camera-source/com/mitsubishielectric/ada/app/camera/activity/LaneWatchSettingActivity.smali:1710)
- No raw OBD PID, diagnostic service/payload, or FYT CAN-box equivalent is established by these OEM Binder APIs. A compatible transport needs its own trace and supported-hardware checks.
